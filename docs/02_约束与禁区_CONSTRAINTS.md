# 约束与禁区（必须遵守）

## 1) 编译与性能约束
- 禁止引入 float/double
- 尽量避免 64位乘除，尤其 64位除法（避免链接 __muldi3/__udivdi3 等）
- 任何定标请使用定点：mV/mA/0.1℃/0.1%SOC

## 2) 协议兼容性
- 不允许改变 Modbus 寄存器地址/含义/缩放/字节序
- 不允许随意改变 BLE GATT 服务/特征/notify 数据格式（除非明确版本升级策略）

## 3) SDK 修改策略
- 默认不修改 stack/、drivers/ 等 SDK 核心代码
- 若必须改 SDK：必须在报告中说明原因、影响、回滚方案

## 4) 安全策略
- AFE通信失败、数据不可信、存储校验失败等必须触发安全降级
- 不允许用旧缓存数据掩盖异常

## 5) 改动方式
- 必须最小改动
- 每次改动给出验证方法（编译 + 关键日志点/测试步骤）
